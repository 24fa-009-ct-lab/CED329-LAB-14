
# CED329 Lab 14 - GraphQL API Development

## Project Overview
A full-stack Product Management Application developed using React, Node.js, Express.js, and GraphQL.

## Technologies Used
- React.js
- Node.js
- Express.js
- GraphQL
- express-graphql
- graphql-request
- CORS

## Features
- Fetch all products using GraphQL queries.
- Add new products using GraphQL mutations.
- Display product names and prices.
- React frontend integrated with GraphQL backend.

## Project Structure
- graphql-lab-backend: GraphQL API server.
- graphql-lab-frontend: React application.
- README.md: Project documentation.

## How to Run

### Backend
1. Open the backend folder.
2. Install dependencies using npm install.
3. Run node index.js.
4. Backend runs at http://localhost:5000/graphql.

### Frontend
1. Open the frontend folder.
2. Install dependencies using npm install.
3. Run npm start.
4. Frontend runs at http://localhost:3000.

## GraphQL Operations
- Query: Fetch all products.
- Mutation: Add a new product.
